# 🍜 Joto Ramen Website

A complete restaurant website with customer ordering and admin panel.

## 🚀 Quick Start

### **Open Website**
```
Double-click: public/index.html
```

### **Open Admin Panel**
```
Double-click: public/admin.html
Login: admin / admin123
```

## 📁 Files

```
public/
├── index.html      # Customer website
├── script.js       # Website logic
├── styles.css      # Website styles
├── admin.html      # Admin panel
├── admin.js        # Admin logic
└── admin-styles.css # Admin styles
```

## ✨ Features

### **Customer Website**
- ✅ Browse menu (10 items)
- ✅ Add to cart & order online
- ✅ Customer login/signup
- ✅ Submit reviews
- ✅ View gallery
- ✅ Make reservations
- ✅ See locations with maps

### **Admin Panel**
- ✅ Dashboard with stats
- ✅ Add/delete menu items
- ✅ Upload gallery images
- ✅ View/delete orders
- ✅ View/delete reviews
- ✅ See registered customers
- ✅ Change admin password

## 🎨 Customization

### **Change Admin Password**
1. Login to admin panel
2. Go to Settings
3. Enter current & new password
4. Click "Change Password"

### **Add Menu Item**
1. Admin → Menu → "Add Menu Item"
2. Fill: Name, Description, Price, Category
3. Add image URL (optional)
4. Click "Save"

### **Upload Gallery Image**
1. Admin → Gallery → "Add Image"
2. Select image file from computer
3. Add description (optional)
4. Click "Add"

## 💾 Data Storage

All data saved in browser localStorage:
- Menu items
- Gallery images
- Customer reviews
- Orders
- Customer accounts

**Data persists even after closing browser!**

## 🌐 Deploy

### **Netlify (Easiest)**
1. Go to https://app.netlify.com/drop
2. Drag `public` folder
3. Get live URL instantly!

### **GitHub Pages**
1. Create GitHub repo
2. Upload `public` folder contents
3. Enable GitHub Pages in settings
